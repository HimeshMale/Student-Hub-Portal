 Student Hub Portal

A simple web-based Student Hub Portal built using HTML,CSS and Javascript. The portal allows students to access academic information such as attendance, fees, study material, timetable, upcoming events, results, and profile details, along with basic login and registration functionality.

Features
 Login and Registration pages
 Attendance record
 Weekly Timetable
 Fees summary
 Study Material list
 Upcoming Events
 Semester Results
 Student Profile
 Contact form

 Tech Used
 HTML5
 CSS3
 Javascript(will be used)
